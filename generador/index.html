📊 Generador de estadísticas

Convierte un CSV exportado desde VideoCuts en los ficheros de datos que necesita la web de estadísticas. Todo ocurre en tu navegador — el CSV no sale de tu ordenador hasta que tú subas los ficheros generados.

1. Tipo de estadística
2. Fichero(s) CSV
Ningún fichero elegido
Normalmente subirás el CSV de un solo partido/jornada, pero puedes elegir varios a la vez si tienes más de uno pendiente.
3. Generar
Cómo encaja esto en el proceso
  1. En VideoCuts: Estadísticas → Configurar exportación CSV (con "Equipo" incluida) → Generar CSV, uno por partido/jornada.
  2. Aquí: elige el tipo, sube ese CSV y pulsa "Generar datos" — el generador mira solo lo que ya está publicado en la web para no duplicar nada.
  3. Se descargan un par de ficheros pequeños (los datos de este rival/jornada + el índice actualizado) — súbelos a la carpeta data/lanzamientos/ de este repositorio y haz git add data/lanzamientos , git commit -m "Mensaje" y git push
  4. Ese rival aparece en la portada de la web — se entra en él y se ve lo suyo.
